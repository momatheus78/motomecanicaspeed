# 🎬 Studio Viral — Agente de Criação Autônoma

Sistema completo de IA para descobrir nichos, criar roteiros virais, 
editar vídeos e monetizar conteúdo no YouTube, TikTok e Instagram.

---

## 🚀 Como usar (2 passos)

### Passo 1 — Abra o arquivo
Clique duas vezes no arquivo `index.html`
Ele abre direto no seu navegador (Chrome, Edge ou Firefox).

### Passo 2 — Cole sua chave de API
1. Acesse: https://console.anthropic.com/settings/keys
2. Crie uma conta gratuita (tem créditos iniciais)
3. Clique em "Create Key" e copie a chave (começa com `sk-ant-...`)
4. Cole no campo no topo do Studio Viral e clique "Salvar"

Pronto! O sistema já funciona com busca web em tempo real.

---

## 🔧 O que cada aba faz

| Aba | Função |
|-----|--------|
| 🎯 Descobrir Nicho | Analisa seu perfil e recomenda os 3 nichos mais lucrativos |
| 📈 Tendências | Busca o que está viral AGORA na plataforma escolhida |
| 📝 Roteiro | Gera roteiro completo com gancho, desenvolvimento e CTA |
| ✂️ Edição | Monta workflow personalizado com ferramentas para seu nível |
| 💰 Monetização | Mapeia todas as fontes de receita e projeta ganhos |
| 🤖 Modo Autônomo | Plano semana a semana para automatizar tudo |

---

## 💡 Ferramentas gratuitas para começar

- **Roteiro**: Claude.ai / ChatGPT
- **Narração IA**: ElevenLabs.io (10.000 caracteres/mês grátis)
- **Edição**: CapCut (celular e PC) — gratuito
- **Imagens/vídeos**: Pexels.com, Pixabay.com — royalty free
- **Agendamento**: Buffer.com (3 canais grátis)
- **Automação**: n8n.io (self-hosted, gratuito)
- **Análise**: TubeBuddy, VidIQ (planos gratuitos)

---

## 🔒 Segurança

Sua chave de API fica salva localmente no seu navegador (localStorage).
Ela nunca é enviada para nenhum servidor além da Anthropic.
