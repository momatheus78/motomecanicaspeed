⚙️ Configurar Ollama
Siga os 3 passos abaixo. Precisa fazer isso só uma vez. Depois o Studio funciona 100% offline, de graça, para sempre.
1
Baixar e instalar o Ollama

Acesse o site oficial e baixe para Windows, Mac ou Linux:

🌐 ollama.com/download

Instale normalmente como qualquer programa. O Ollama vai rodar em segundo plano automaticamente.

2
Baixar um modelo de IA

Abra o Prompt de Comando (Windows) ou Terminal (Mac/Linux) e rode um dos comandos abaixo:

ollama pull llama3.2

Escolha o modelo conforme seu PC:

⭐ llama3.2 2GB • recomendado llama3.1 4.7GB • mais inteligente mistral 4.1GB • ótimo texto gemma2 5.5GB • bom PT-BR qwen2.5 4.7GB • multilingual phi3 2.2GB • PC fraco
3
Liberar acesso do navegador ao Ollama

Por padrão o Ollama só aceita conexões locais. Para o Studio funcionar no navegador, rode este comando uma única vez:

OLLAMA_ORIGINS=* ollama serve

Windows: No PowerShell, use:

$env:OLLAMA_ORIGINS="*"; ollama serve

Deixe o terminal aberto enquanto usa o Studio. Após configurar uma vez, pode criar um atalho para isso.
